# اطلس — Atlas

تطبيق خرائط iOS جديد للمطوّر عبدالباسط خضير (ابو العبد).
مشروع منفصل تماماً عن «وجهتي» (Wijhati) وعن IQMap — لا يشاركهما كوداً ولا مستودعاً.

> الحالة: **هيكل أولي (Skeleton) — v0.1.0**
> الواجهات والخدمات مبنية بحدود واضحة، وبعضها يعمل فعلياً عبر الخدمات العامة المجانية،
> وبعضها هيكل بانتظار مرحلته (مذكور بصراحة تحت «حدود معروفة»).

## الفكرة

«خريطة العراق يبنيها العراقيون» — خريطة عربية أولاً فوق بيانات OpenStreetMap المفتوحة،
بمكدّس مجاني بالكامل، وميزة أساسية: أماكن محلية يضيفها المستخدمون أنفسهم
(محلات، أزقّة، معالم غير موجودة بالخرائط العالمية).

## المكدّس

| الطبقة | الاختيار | ملاحظة |
|---|---|---|
| الواجهة | SwiftUI + iOS 17+ | خريطة بملء الشاشة، Liquid Glass، RTL عربي كامل |
| العرض | MapLibre Native | بلاطات OpenFreeMap (بدون مفتاح) — ستايل نهاري/ليلي تلقائي |
| البحث أثناء الكتابة | Photon (photon.komoot.io) | العام للتجربة؛ الإنتاج يحتاج استضافة ذاتية بفهرس عربي |
| تفاصيل المكان | Nominatim | للتفاصيل والـ reverse فقط — سياسته تحظر الـ autocomplete |
| الاتجاهات | Valhalla (العام التجريبي) | تعليمات عربية؛ الملاحة خطوة بخطوة (Ferrostar) مرحلة لاحقة |
| الأوفلاين | MapLibre Offline Packs | تنزيل بلاطات محافظات (بغداد/أربيل/البصرة كأمثلة) |
| الأماكن المحلية | JSON محلي الآن | واجهة `LocalPlacesSyncing` جاهزة لربط Supabase لاحقاً |
| الأماكن المحفوظة | UserDefaults + App Group | بيت/شغل + ودجت شاشة رئيسية |

## البناء

المشروع يُولّد بـ XcodeGen من `project.yml` (نفس نمط مشاريع المطوّر):

```sh
brew install xcodegen
xcodegen generate
# ثم افتح Atlas.xcodeproj — أو دع GitHub Actions يبني IPA غير موقّع
```

عند إنشاء المستودع: فعّل Workflow المرفق `.github/workflows/build.yml`
وسيبني `Atlas-unsigned.ipa` كـ artifact عند كل push إلى `main`،
ويوقّعه المطوّر بأداته المعتادة (iStore).

## حدود معروفة (بصراحة)

- **البحث والاتجاهات أوفلاين غير جاهزين**: التنزيل الحالي يحفظ بلاطات الخريطة فقط.
  البحث/التوجيه على الجهاز مرحلة لاحقة تقنياً (فهرس محلي + valhalla-mobile).
- **Photon/Valhalla العامان للتجربة**: حدود استخدام وبلا ضمان توفر؛ الإطلاق يحتاج استضافة ذاتية.
  (مُتحقق حياً 2026-10-13: Photon العام يرفض `lang=ar` — يدعم default/de/en/fr فقط —
  لذلك الكود لا يرسل لغة؛ أسماء العراق ترجع بالعربية من `name` أصلاً.
  وValhalla العام يرجع التعليمات بالإنكليزية رغم طلب `ar-AE` — العربية تحتاج المستضاف ذاتياً.)
- **مزامنة الأماكن المحلية غير مفعّلة**: تُحفظ محلياً بصيغة JSON؛ الرفع إلى Supabase هيكل واجهة فقط.
- **الملاحة الصوتية خطوة بخطوة (Ferrostar) غير مدمجة بعد**: الاتجاهات الحالية قائمة خطوات + خط على الخريطة.
- لم يُبنَ المشروع بعد على macOS/Xcode — أول بناء فعلي يكون عبر GitHub Actions بعد إنشاء المستودع.
